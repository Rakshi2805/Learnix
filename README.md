# Learnix – Personalised AI Tutor for Learning AI

Learnix is a personalised AI tutor that adapts learning to a learner's knowledge level, goals, learning pace, and quiz performance.

## Features

- Learner Profile
- Diagnostic Assessment
- Personalised Learning Roadmap
- AI-Powered Tutor
- Topic Quizzes
- Adaptive Learning Recommendations
- Progress Dashboard

## Learning Workflow

Learner Profile
→ Diagnostic Quiz
→ Personalised Roadmap
→ AI Tutor
→ Topic Quiz
→ Adaptive Recommendation
→ Progress Dashboard

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- OpenRouter API
- Node.js
- Git & GitHub
